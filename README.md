💰 Expense Tracker Web App

A simple and interactive **Expense Tracker** built using HTML, CSS, and JavaScript to help users manage their income, expenses, and budget efficiently.

----------------------------------------------------------------------------------------------------------------------------------------------------------------

🚀 Live Demo

👉 https://lsn-expense-tracker.netlify.app/

----------------------------------------------------------------------------------------------------------------------------------------------------------------

📌 Features

* 🔐 **Login System (Local Storage Based)**
* ➕ **Add Income & Expenses**
* 📊 **Real-time Balance Calculation**
* 🧾 **Transaction History with Delete Option**
* 📅 **Category & Date Tracking**
* 💸 **Monthly Budget Setting**
* ⚠️ **Budget Exceeded Alert**
* 📈 **Visual Reports using Chart.js**
* 📱 **Responsive Design**

----------------------------------------------------------------------------------------------------------------------------------------------------------------

🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Charts:** Chart.js
* **Storage:** LocalStorage (Browser-based)

----------------------------------------------------------------------------------------------------------------------------------------------------------------

▶️ How to Run

1. Download or clone this repository

   git clone https://github.com/your-username/expense-tracker.git
   
3. Open the project folder

4. Run the app by opening:

   index.html
   
No installation required 🚀

----------------------------------------------------------------------------------------------------------------------------------------------------------------

🔑 Usage

* Enter any **User ID & Password** (Demo purpose only)
* Add transactions (income/expense)
* Set a **monthly budget**
* View:
  * Total Income
  * Total Expenses
  * Current Balance
* Check **Reports** for visual insights

----------------------------------------------------------------------------------------------------------------------------------------------------------------

⚠️ Note

* This is a **frontend-only project**
* Data is stored in **browser LocalStorage**
* Clearing browser data will remove all saved transactions
